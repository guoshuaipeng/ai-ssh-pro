## 0. 现象复核（像素 + 代码，09:55 CST）

审计里记为「双行折行」，放大像素与 master `502591bc` 代码后更正为：

| 观察 | 实际原因 | 代码锚点 |
|---|---|---|
| 标签下多出一条「第二行」，顶区变厚 ~8px | **不是 flex-wrap**，是 `.tab-bar { overflow-x:auto }` 的**横向滚动条带**（全局 `*::-webkit-scrollbar{height:8px}`）常驻显示 | `styles.css` L1238–1252、L120–150 |
| 左端出现 `‹` 小箭头 / 首个标签贴边被切 | 滚动条按钮 + 无边缘提示 | 同上 |
| 告警铃 🔔 不见了 | 铃和广播徽标是 `.tab-bar` 的子元素，**随标签一起滚出视口** | `App.tsx` L3924–3952 |
| 看不出还有几个标签没显示 | 无溢出入口、无计数 | — |

结论：用户感知的「两行 / 变厚 / 乱」= 滚动条带 + 无溢出入口 + 固定元素被滚走。设计目标是**一行 36px、无可见滚动条、溢出有序可达**。

## 1. 目标

1. 标签条**永远一行、固定 36px**（含底边线），与标签数量无关。  
2. 放不下的标签**不靠可见滚动条**表达，而是：边缘渐隐 + 右端「所有标签 ⌄ n」入口。  
3. 告警铃 / 广播徽标等**固定元素不随标签滚动**。  
4. 不新增工具栏按钮；不新增全局快捷键。

## 2. 入口

| 入口 | 位置 | 行为 |
|---|---|---|
| **所有标签 ⌄ n** | 标签条最右固定区（仅溢出时出现） | 打开「标签列表」浮层；`n` = 当前**未完整显示**的标签数 |
| Ctrl+K「切换标签…」 | 命令面板（UX-11b「视图」类） | 打开同一列表，焦点在搜索框；别名 `tab` / `qhbq` |
| 既有 | 点击标签、Ctrl+Tab / Ctrl+1..9、标签右键（UX-14 §4）、拖拽排序 | 不变；切到隐藏标签时自动滚入视口（`scrollIntoView inline:nearest`） |

**不**做：滚动箭头 ‹ ›、第二行、标签区「更多」文字按钮、工具栏新钮。

## 3. 布局（1366×768）

```
┌ 标签条 36px ───────────────────────────────────────────────────────────────────────┐
│ 🔔2 │░ 运维首页 × │ web-01 × │ web-02 × │ db-prod-01 × │ … │ 告警工作台 ×░│ ⌄ 3 │ ●广播 2 │
└─────┴──────────────────── 可滚动区（无滚动条，两端 24px 渐隐）──────────┴────┴────────┘
 固定左                                                                         固定右
```

| 区 | 规则 |
|---|---|
| 容器 `.tab-bar` | `height:36px`（含 1px 底边）；`display:flex; flex-wrap:nowrap; overflow:hidden`；`padding:6px 8px 0` |
| 固定左 | 告警铃（及计数徽标）。**移出滚动区**，常驻可见 |
| 滚动区 `.tab-bar-scroll` | `flex:1; min-width:0; overflow-x:auto; overflow-y:hidden`；**隐藏滚动条**：`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`（覆盖全局 thin/8px） |
| 标签 `.tab` | **高度固定 30px**（=36−6 顶距），`padding:0 8px 0 12px`，`flex:0 1 auto; min-width:112px; max-width:200px`；标题 ellipsis；`×` 常驻 18px |
| 当前标签 | `min-width:140px`；不被压缩到更窄；切换后自动滚入可视区 |
| 顶边色（生产/只读） | **所有标签预留 2px 透明顶边**，`tab-guard-prod/ro` 只换色 → 各标签等高（现状仅 guard 标签多 2px，基线错位） |
| 边缘渐隐 | 左/右有隐藏内容时，对应端 24px `mask-image` 渐隐；无隐藏时不渐隐 |
| 滚轮 | 鼠标竖向滚轮在标签条上 → 横向滚动（`deltaY → scrollLeft`）；触控板横滑原生 |
| 固定右 | `⌄ n` 按钮（28×24，文字 `⌄ 3`，`nowrap`）→ 广播徽标（如有）。不溢出时 `⌄` **不渲染**，不占位 |
| 拖拽排序 | 拖到滚动区两端 32px 内时自动横滚（≈8px/帧） |

**密度预算（示意，内容宽口径见 UX-54）**

| 场景 | 标签区可用宽 ≈ | 112px 最小宽下可见 ≈ |
|---|---|---|
| 1366 · `sidebar=collapsed` | ~1270px | 11 个 |
| 1366 · `sidebar=expanded` | ~1020px | 8–9 个 |
| 1024 窗 | ~700px | 5–6 个（`min-width` 降到 96px） |

→ live 11 标签场景：收起侧栏基本全显；展开侧栏 2–3 个进 `⌄`，一行、无滚动条。

### 为什么用 `⌄` 不用 `⋯`

本产品 `⋯` 已定义为「更多操作」（页头 UX-30/48、L2 浮层、L7 右栏）。标签溢出是「**列出全部标签**」，用 `⌄`（v0.4.2 UX-12a 换 lucide `chevron-down`）+ 计数，与操作类 `⋯` 分开，避免同一符号两种含义。

## 4. 标签列表浮层

```
                                         ┌ 所有标签（11） ─────────────┐
                                         │ 🔍 搜索标签                  │ ← 仅 ≥10 个标签时显示
                                         ├─────────────────────────────┤
                                         │ ▍运维首页                    │
                                         │ ▍web-01                  ×  │ ← hover 才显示 ×
                                         │ ▍db-prod-01        生产      │
                                         │ ▍告警工作台          ✓       │ ← 当前标签：✓ + 高亮底
                                         │ ▍web-02 (已断开)    ●        │ ← 橙点
                                         │ …                            │
                                         ├─────────────────────────────┤
                                         │ 关闭已断开的会话（1）        │ ← 仅 n>0 时显示
                                         └─────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 位置 | 右对齐 `⌄` 按钮下方；宽 280（min 240 / max 360）；`max-height: min(60vh, 420px)` 内部滚动 |
| 行 | 28px；左 3px kind 色条（同 UX-14 §1 / `tab-kind-*`）；标题 ellipsis + tooltip 全称与 `user@host:port`；右侧徽标最多一枚（生产/只读/REC/断开，承 UX-53「单徽标」） |
| **标题来源** | **必须与标签条同一渲染函数**（如 `tabLabel(t)`）：首页/告警/审计等工作台标签按当前语言实时取 i18n，连接中/已断开带状态后缀。**禁止**直接用 `t.title`（工作台标题是创建时语言，切中英后会错） |
| 顺序 | 与标签条顺序一致（不分组，不重排） |
| 当前标签 | ✓ + `--accent` 浅底；`aria-current="true"` |
| 点击行 | 切换到该标签 → 滚入可视区 → 关闭浮层 |
| 行内 × | 关闭该标签（同标签 ×，走既有 closeTab 确认规则）；浮层不关闭，计数刷新 |
| 搜索 | ≥10 个标签显示；按标题/主机名/拼音首字母过滤（复用命令面板匹配器）；打开即聚焦 |
| 页脚 | 「关闭已断开的会话（n）」仅 n>0 显示；不放其他批量操作（关闭其他/右侧仍在标签右键） |
| 键盘 | ↑↓ 移动、Enter 切换、Delete 关闭高亮项、Esc 关闭浮层并还焦点到 `⌄`；输入字符直接进搜索 |
| 关闭浮层 | Esc / 点外部 / 再点 `⌄` / 切换标签后 |

## 7. 1366 密度笔记

- 量的是**标签条所在 `.main` 宽**（扣侧栏），与 UX-54「内容宽」口径一致；截图标注 `sidebar=collapsed|expanded`。  
- 失败判据：标签条高度 ≠ 36px；出现可见横向滚动条；任何标签文字被**纵向**裁切；铃被滚走；`⌄` 按钮或标签标题逐字换行。  
- 1024：同规则，`min-width:96px`，列表宽 240。

## 8. 与当前 Dev 实现的差异（CloudAgent bc-13f5db03，transcript 09:5x 快照）

Dev 已做：`.tab-bar` 36px + `overflow:hidden`；新 `.tab-bar-scroll`（`flex-wrap:nowrap`）；铃在滚动区外；溢出时 `⋯` 按钮 + `tab-overflow-menu` 列表；`ResizeObserver` 测量。方向正确，以下需对齐：

| # | 差异 | 风险 | 级 |
|---|---|---|---|
| D1 | `.tab-bar-scroll` 仍 `scrollbar-width:thin`（全局 8px）且外层 36px `overflow:hidden` | 滚动条吃掉滚动区底部 8px，30px 区内放 ~34px 标签 → **标签底部被裁 / 活动标签与内容区接缝断开**，比原来更难看 | **MUST** |
| D2 | 标签未定高（靠 padding 8px 撑 ~34px） | 同 D1；需 `height:30px` + 竖向居中 | **MUST** |
| D3 | 列表行用 `t.title` | 首页/告警/审计标签在切换语言后显示旧语言；连接状态缺失 | **MUST** |
| D4 | 列表无 Esc / 外点关闭、无当前标记 | 浮层卡住；看不出在哪个标签 | **MUST** |
| D5 | 生产/只读标签 `border-top:2px` 仅加在 guard 标签 | 等高被破坏，固定 36px 下 guard 标签更易被裁 | **MUST** |
| D6 | 按钮符号 `⋯`、无计数；文案「更多标签」 | 与「更多操作」混义；不知道藏了几个 | SHOULD |
| D7 | 标签 `flex-shrink:0`、无最小宽压缩 | 1366 展开侧栏时可见标签偏少 | SHOULD |
| D8 | 无边缘渐隐、无竖滚轮→横滚 | 隐藏滚动条后用户不知道还能滚 | SHOULD（D1 改后建议同 PR） |
| D9 | 列表搜索 / 行内 × / 关闭已断开 / Ctrl+K「切换标签…」 | 便利项 | NICE（可留 0.4.2） |
