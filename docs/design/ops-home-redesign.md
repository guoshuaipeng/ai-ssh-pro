# 运维首页（OpsHomeTab）重设计 · 设计稿 v1

## 1. 现状盘点（0.6.54）

截图：宽 1400 / 窄 960，深浅两套。页面上现在有这些元素：

| 区域 | 元素 | 数据 / 动作 |
| --- | --- | --- |
| 页头 | 标题 + `{n} 台主机 · {a} 条告警`；**新建连接**（主按钮）；`⋯` 更多 | 更多菜单：打开看板、告警规则、运维剧本、巡检（a3）、启动设置、刷新摘要、探测设置 |
| 首周任务条 | `首周任务 x/y` | onTasks |

| 快捷操作（右栏，≤1100 折叠进 ⋯） | 新建连接（与页头重复）、打开看板（重复）、运行剧本…、打开 SFTP、同步文件夹…；最近剧本 + 全部剧本 | onPlaybook、onOpenSftp、onSyncFolder、onOpenRecent |
| 无主机态 | 标题 / 描述、新建、导入会话、试用演示主机、新手引导、从云同步恢复；示例剧本 | onImport、onDemo、onTour、onRestoreSync、onSample |

**问题：** 三栏互相抢注意力；主次不分（三个区块的标题字号、按钮都一样）；入口重复（新建连接 ×2、看板 ×2）；右栏在宽屏下大面积空着，窄屏又换成另一套布局（rail 折叠进 ⋯）；控件密度不均（一张很小的主机卡片配一个整行宽的按钮）；告警空态是一张大卡片，比真正的告警还显眼；「主机离线」和「告警」本是同一件事——**需要我处理**——却分在两栏。

## 2. 设计原则（DataAI 标准）

- 安静的 chrome：只有一个主按钮（新建连接）；其余都是次级按钮 / ghost / 链接。
- 一列、三个区块，按优先级从上往下：**需要处理 → 主机 → 快捷**。
- 宽窄屏**同一套结构**，只调列数和留白，不切换成另一种布局。
- 间距只用 token：页面 `--space-5/6`、区块之间 `--space-5`、卡片内 `--space-3/4`；内容最大宽度 1080px 居中。
- 字号层级：页标题 `--fs-xl`/600 → 区块标题 `--fs-md`/600 → 正文 `--fs-base` → 元信息 `--fs-sm` muted → 指标 `--fs-xs` mono。

## 3. 布局

```
页头：运维首页（--fs-xl）                         [⟳] [⋯] [+ 新建连接]
      ● 1 台在线 · ● 1 台无法连接 · 2 条待处理 · 更新于 1 分钟前
[首周任务 2/5 ▬▬▭▭ 下一步：…  继续  ×]          ← 仅在未完成时显示，可收起
需要处理 2  [进行中|全部|已忽略]      (告警已静默至 17:02 · 取消)  告警工作台 →
┌ ● demo-db-01   无法连接 · 超时（3 次重试后停止）    3 分钟前   [重试][编辑连接][忽略] ┐
└ ● demo-web-01  磁盘 /var 87%（阈值 85%）           12 分钟前   [AI 解读][连接终端][忽略]┘
主机 2   [全部连接 ▾] [☐ 排除只读]                         在看板中查看全部 →
[web-01 卡片：负载/内存/磁盘条 + 终端/SFTP/看板] [db-01：无法连接] [+ 新建连接（虚线）]
快捷                                                            全部剧本 →
[▷ 运行剧本…] [打开 SFTP] [同步文件夹…] | 最近剧本  滚动重启 nginx  磁盘清理
```

### 3.1 页头
- 元信息行用状态点做主机计数（在线 / 无法连接）+ 待处理数 + 「更新于 x 前」。原先的 `自动采样 · 间隔` 状态并到这里，探测中显示为小 spinner。
- `⟳` 刷新（F5，tooltip 写明快捷键）、`⋯`（看板、告警规则、运维剧本、巡检、启动设置、探测设置）、**新建连接**（唯一的主按钮，显示快捷键）。

### 3.2 需要处理（主区块）
- **合并：** 进行中的告警 + 无法连接 / 探测失败的主机，放在同一个列表里，按严重度、再按时间排序。
- 行：严重度点、主机（等宽列 160px）、消息（单行省略，完整内容放 tooltip）、相对时间、行内动作（**悬停 / 聚焦时才显示**）。
  - 告警：AI 解读、连接终端、忽略（可撤销 toast）；生成修复剧本放进行的 `⋯`。
  - 主机：重试、编辑连接、忽略。
- 区块头：分段筛选（进行中 / 全部 / 已忽略）、静默 chip（`告警已静默至 hh:mm · 取消`，代替原来的整条横条）、「告警工作台 →」链接（代替按钮）。
- 空态：**一行字**（不再是卡片）——`✓ 一切正常 · 规则在后台运行 · 告警规则 →`，高度 44px。
- 超过 5 条：显示前 5 条 + 「还有 n 条 · 在告警工作台查看」。

### 3.3 主机
- 网格 `repeat(auto-fill, minmax(240px, 1fr))`：1400 宽约 3–4 列，960 宽 2 列。
- 卡片：状态点、名称、保护标签（prod / 只读）、延迟（mono）；三条细指标条：负载 / 内存 / 磁盘（达到阈值用 warn / danger 色）；inode / 挂载缺失合并成一行 muted 提示。
- 底部动作：终端 / SFTP / 看板（小号次级按钮）。整张卡片可点击，**单击 = 连接 / 切到会话**。
- 离线 / 无法连接卡片：只显示一行状态，详细原因在「需要处理」里（不重复）。
- 最后一格是虚线的「+ 新建连接」卡片；超过 8 台：显示 8 台 + 「在看板中查看全部 →」（区块头里也有这个链接，代替原来整行宽的按钮）。
- 区块头：范围下拉、排除只读开关（ghost 样式），筛选计数 / 清除筛选也放在这里。

### 3.4 快捷
- 一行按钮：运行剧本…、打开 SFTP、同步文件夹…；竖分隔线后是「最近剧本」（ghost 按钮，最多 3 个）+ 「全部剧本 →」。
- 删掉右侧 rail，以及里面重复的「新建连接」「打开看板」。

### 3.5 无主机态（同一个页面骨架）
- 页头不变（新建连接仍是主按钮）；「需要处理」和「主机」两个区块换成**一张居中卡片**（最大宽度 560px）：标题「开始搭建你的运维工作台」、一句说明、三个动作：**新建连接**（主）、导入会话…、试用演示主机；下面一行链接：新手引导 · 从云同步恢复。
- 「快捷」区块保留，示例剧本放在这里（滚动重启 nginx / 磁盘清理）。

## 6. 交互

- **点击目标：** 行、卡片的高度 ≥ 32px；行内动作按钮高 26px，相邻间隔 4px。
- **悬停：** 行使用 `--color-row-hover-bg` 并显示动作；卡片描边变 accent + `--shadow-sm`；不做位移动画。
- **键盘：**
  - 页面内 `Tab` 依次经过：页头动作 → 需要处理列表 → 主机网格 → 快捷。
  - 列表和网格内是 roving tabindex：↑↓（列表）、←→↑↓（网格）移动焦点，`Enter` = 主动作（告警：AI 解读；主机：连接），`Delete` = 忽略，`.` 或 `Shift+F10` 打开行菜单。
  - `F5` 刷新；`Ctrl+Shift+N` 新建连接（现有）。
- **反馈：** 忽略有可撤销 toast；重试时行内显示 spinner；刷新时元信息变成「正在更新…」。
- **保持不变：** 现有的 `data-testid`（`ops-home`、`l7-card`、`l7-mute`、`l7-open-dashboard`、`l7b-*`、`l7c-*`、`l7d-*` 等）迁移到新位置时保留；ARIA 菜单语义不变。
