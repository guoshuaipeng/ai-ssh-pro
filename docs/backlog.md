## 1. D5 SFTP 远程文件编辑后自动回传 + 冲突提示（P0）
- 理由：改配置文件是 SFTP 最常见的用途。现在回传不检查远端版本，有可能覆盖别人的改动，每次编辑都有风险。
- 验收：
  - 本地保存后自动上传，并显示 toast。
  - 远端 mtime 或大小变化时，提示用户选择“覆盖 / 查看差异 / 放弃”。
  - 只读主机禁止回传，并说明原因。

## 2. D6 选区或错误一键“问 AI”，并按标签保留对话（P0）
- 理由：AI 对话是本产品的核心差异点。现在的“用 AI 解释”只能问一次，追问时要手动复制上下文。
- 验收：
  - 右键选区选“问 AI”，追加到当前标签的对话里，附带主机和 cwd（可以复用 D2 的 cwd 记录）。
  - 对话可以继续追问，关闭标签后释放。

## 3. D7 粘贴多行命令前的确认与预览（P1）
- 理由：粘贴是终端里最常见的输入方式之一。误粘多行会立刻逐行执行，在生产机上风险很高。
- 验收：
  - 粘贴超过 1 行时弹出预览，显示行数和高危命令标记。
  - 可以选择“全部粘贴 / 合并成一行 / 取消”。
  - 只读主机仍然拦截。
  - 可以设置为“不再询问”（生产机除外）。

## 4. D8 标签页会话恢复：重启应用后重新打开上次的标签与目录（P1）
- 理由：每天开机或升级后都要重新打开一组主机。D2 已经有了 cwd 记录，可以复用。
- 验收：
  - 退出时记住打开的标签（不保存密码）。
  - 启动时提示“恢复 N 个标签”。
  - 连接完成后回到各自的 cwd。

## 5. D9 自定义 PS1 / zsh 的 cwd 识别（Shell Integration，可选开启）（P2）
- 理由：补上 D2 的已知限制；同时可以去掉 B1 退出码后缀的回显。
- 验收：
  - 按主机开关，默认关闭。
  - 开启后一次性注入 precmd，用 OSC 7 上报 cwd、用 OSC 777 上报 `$?`，不覆盖已有的 PROMPT_COMMAND。
