## 排序

### 1. D2 断线自动重连 + 重连后恢复工作目录与上下文（P0）
- 理由：每个会话都会遇到。笔记本休眠、VPN 切换、网络抖动后，现在要手动重连并重新 `cd`，是高频且每次都要动手的痛点。
- 验收：
  - 断线后按 1s、2s、5s…退避自动重连，状态栏显示倒计时，可以取消。
  - 重连成功后回到原来的 cwd。
  - 只读或生产主机只重连，不重放任何命令。

### 2. D3 命令历史 / 片段面板：Ctrl+R 模糊搜索（P0）
- 理由：几乎每条命令都可能来自历史。代码里已经有 smart-history 和 snippet 的数据，但缺少一个全局的、可搜索的入口。
- 验收：
  - Ctrl+R 打开主题化浮层，按当前主机和全局分组模糊匹配。
  - Enter 填入终端，不自动执行；Alt+Enter 执行时走安全分级。

### 3. D4 多主机快速切换器：Ctrl+P / Ctrl+Tab（P1）
- 理由：管理多台主机的用户每天要切换很多次。目前只能点侧栏或标签，标签一多就很难找。
- 验收：
  - Ctrl+Tab 按最近使用的顺序在标签间切换。
  - Ctrl+P 模糊搜索已保存的主机和已打开的标签，并显示在线状态与保护级别。

### 4. D5 SFTP 远程文件“编辑后自动回传”与冲突提示（P1）
- 理由：改配置文件是 SFTP 最常见的用途。需要回传时检测远端是否已被修改，防止覆盖别人的改动。
- 验收：
  - 本地保存后自动上传，并显示 toast。
  - 远端 mtime 变化时提示用户选择“覆盖 / 对比 / 放弃”。
  - 只读主机禁止回传，并显示原因。

### 5. D6 AI 对话：从终端选区或错误一键带上下文提问，并保留会话（P1）
- 理由：AI 对话是本产品的核心差异点。目前“用 AI 解释”只能单次使用，不能延续追问，把输出复制到对话里也要好几步。
- 验收：
  - 选区右键选“问 AI”，追加到当前对话，附带主机和 cwd。
  - 对话按标签页保留，可以继续追问。
