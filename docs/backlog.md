## 1. D18 输出分块默认开启评估 + 首次引导（P0）
- 理由：D10/D11/D15/D16 的价值都挂在分块上，但分块默认关，多数用户看不到。现在分块条已稳定、有退出码、有键盘操作，值得评估默认开（或首次运行命令后提示一次）。
- 验收：评估结论写进设计文档；若默认开，确认不挤压终端可视行数（默认高度、自动收起空条）。

## 2. D17 分块按主机持久化 + 搜索分块输出（P1）
- 理由：重连 / 切标签 / 重启后分块丢失；回看之前的输出只能滚动。D8 已恢复标签与目录，分块是下一块缺口。
- 验收：每主机保留最近 N 块（只存本地，可清除）；Ctrl+F 可切到"搜分块"。

## 3. D16b AI 多行脚本：逐行填入 / 作为脚本执行前预览（P1）
- 理由：AI 回答经常给 2–5 行排查命令，现在多行块只能复制，再走 D7 粘贴预览。
- 验收：多行块显示「逐条填入」，每执行完一条自动填下一条；危险行沿用 D7 标红。
