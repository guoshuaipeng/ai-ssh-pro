## 1. D11 命令分块默认开启评估 + 退出码徽标（P0）
- 理由：分块条原来被挤出可视区，相当于没人用过。现在修好了，可以评估是否默认开启。B1 已经能拿到 AI 命令的退出码，可以显示在块头上。
- 验收：
  - 块头显示退出码：0 为绿，非 0 为警告色。用户手动敲的命令显示为“未知”。
  - 失败的块一键“问 AI 为什么失败”。
  - 默认开关保持关闭，但在首次使用时给出提示。

## 2. D12 SFTP 远程窗格“跟随终端目录”（P0）
- 理由：传文件前最常做的就是切到终端当前所在的目录。D2 已经有了 cwd 记录。
- 验收：
  - 远程窗格加一个“跟随终端”开关，终端 cd 后自动跳到同一目录。
  - 手动浏览时暂停跟随，并显示“回到终端目录”。

## 3. D7b 多行粘贴“不再询问”（生产机除外）+ 括号粘贴模式识别（P1）
- 理由：经常粘贴脚本的用户会被反复打扰。

## 4. D13 快速连接栏：输入 `user@host:port` 直接连接，并支持粘贴 ssh 命令（P1）
- 理由：临时连接没保存过的主机是高频场景，现在要先打开表单。
- 验收：
  - Ctrl+P 里输入地址时多出一项“连接 user@host”。
  - 能识别粘贴进来的 `ssh -p 2222 u@h` 命令。
