## 1. D13 快速连接：输入 `user@host:port` 或粘贴 `ssh -p 2222 u@h` 直接连（P0）
- 理由：临时连一台没保存的机器是每天都有的动作，现在必须先开表单填 4 个字段。
- 验收：Ctrl+P / 首页搜索框输入地址时出现"连接 user@host"；识别常见 ssh 参数（-p、-i、-J、-l）；连上后提示"保存为主机"。

## 2. D15 分块键盘导航 + 重新执行（P1）
- 理由：D10/D11 之后分块是查看输出的主入口；回看上一条输出、重跑失败命令是终端里最频繁的操作之一，目前只能鼠标点。
- 验收：Ctrl+↑/↓ 在块之间跳并滚动终端到对应位置；块上"重新执行"（走命令栏同一路径，受保护级别约束）；失败块回车即重跑前先确认。

## 3. D14 Shell Integration（可选开启）（P1）
- 理由：D2/D8/D10/D11/D12 都依赖提示符解析；自定义 PS1/zsh 主题下 cwd 和分块会失准，直接键入的命令也拿不到退出码，B1/D11 的 printf 回显也只能靠它消掉。频率随前面功能上升。
- 验收：一键在会话里注入（不改远端文件）OSC 133/7 钩子；开启后直接键入的命令也有退出码，且无回显后缀；关闭即恢复。
