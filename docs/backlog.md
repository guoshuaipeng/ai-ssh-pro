## 1. D8 重启后恢复上次打开的标签和目录（P0）
- 理由：每天开机或升级后都要重新打开同一组主机。D2 已经有了 cwd 记录，可以复用。
- 验收：
  - 退出时记住打开的标签，不保存任何凭据。
  - 启动时提示“恢复 N 个标签”。
  - 逐个连接，连接后回到各自的 cwd。
  - 生产或只读主机只重新连接，不自动执行任何命令。

## 2. D9 SFTP 传输队列体验：失败重试、断点续传、拖拽上传到当前目录（P0）
- 理由：传文件是仅次于终端的高频操作。大文件中断后要从头再传，失败的条目也不能一键重试。
- 验收：
  - 失败的条目可以一键重试。
  - 大文件中断后从已传位置继续。
  - 把文件拖进终端标签时，上传到该会话当前的 cwd（复用 D2）。

## 3. D10 终端输出的命令块折叠与复制（P1）
- 理由：每天都要复制某条命令的输出，现在只能手动拖选。
- 验收：
  - 按提示符把输出切分成命令块（复用 cwdFromPrompt 的提示符识别）。
  - 悬停时可以“复制输出 / 复制命令 / 问 AI”（与 D6 联动）。

## 4. D7b 多行粘贴“不再询问”（生产机除外）+ 括号粘贴模式的识别（P1）
- 理由：经常粘贴脚本的用户会被频繁确认打扰。远端开启括号粘贴模式时，粘贴不会立即执行，提示可以改得更轻。
- 验收：
  - 设置项“多行粘贴前确认”：对普通主机可以关闭，生产和只读主机强制确认。
  - 远端已开启括号粘贴模式时，提示改为“粘贴后不会自动执行”。
