# D22d 终端直接输入的命令也进入失败捕获与"上次失败"（2026-10-20，第 16 轮）

## 需求
大多数命令是在终端里直接敲的；它们也应记录退出码、带"上次失败"标记，并可"问 AI"带输出。

## 设计
- Shell Integration 钩子（bash/zsh，D14）在 D 之前多发 `OSC 133;E;<fc -l -1>`（经 `tr` 去控制字符），退出码 `$?` 保持不变（已在 bash 实测）。
- 渲染端 parseOsc133E 解析"编号 命令"；编号未变（空回车）视为旧命令，不重复上报 → SHELL_CMD_EVENT。
- 历史（lib/history-exit.ts）：直接输入的命令按原规则写入智能历史（敏感命令、前导空格不记录，受"智能历史"开关控制）；命令栏提交的不重复记录。退出后清空 lastCmd，修正空回车把上一条命令再次标记的问题。
- 失败捕获（D22c）：集成激活时按"提示符到提示符"滚动缓存输出，E 到达时归属命令；敏感命令丢弃输出。仍只在内存。

## 限制
需开启 Shell Integration；HISTCONTROL=ignoredups 时连续重复的同一命令编号不变，只记第一次；history 关闭的 shell 不上报。
