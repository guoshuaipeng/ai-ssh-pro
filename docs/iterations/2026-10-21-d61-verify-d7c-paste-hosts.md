# D61 核对 / D7c 替补：粘贴免询问主机管理

D61 核对：SFTP 高级 → 目录同步（D2，FolderSyncModal 加 shared/folder-sync 的 diffTrees）已经覆盖了这轮要求的范围：
- 递归对比，排除规则可配置，可按大小/时间或哈希比较；
- 先预览新增、修改、多余项，逐项勾选；
- 按钮上写明数量和目标，点击才同步；
- 「删除目标多余文件」默认关闭；生产主机删除前要输入主机名确认。
结论：D61 已覆盖，不重复开发。剩下两点记入 backlog：同一次对比里双向同步；入口在「高级」里不够显眼。

替补 D7c：
- D7b 的「本主机不再询问」只能勾、不能在设置里集中撤销。
- 终端设置里加「多行粘贴不再询问的主机」列表，可单个或全部「恢复询问」。
- 恢复询问会让粘贴更严格，不删除任何数据，所以直接生效。
- 含危险命令的粘贴和生产 / 只读主机规则不变。
