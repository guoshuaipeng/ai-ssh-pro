# D17 分块按主机持久化 + 搜索分块

**PM**：重连、切标签、重启后分块丢失；回看之前的输出只能滚动。

**现状核查**：分块只在组件内存中，无持久化、无搜索。

**方案**
- 每主机（hostKey）保存最近 30 个已结束的分块到本机 localStorage，单块输出只留尾部 8000 字符。
- **生产 / 只读主机不保存**（输出可能含敏感信息），也不显示清除按钮。
- 打开同一主机的会话时恢复为折叠、半透明的历史块；头部出现「清除历史」。
- 头部搜索框：按命令或输出过滤（不区分大小写），显示匹配数；搜索时自动展开匹配块的输出；Esc 清空。

**测试**：test-cycle10 D17 ×3；截图 `blocks-search.png`。

**限制**：只存本机，不随云同步；Ctrl+F 仍是终端查找，分块搜索在分块条里。
