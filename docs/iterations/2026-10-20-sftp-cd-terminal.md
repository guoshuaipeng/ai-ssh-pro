# D28 SFTP「在终端进入」（2026-10-20，第 17 轮）

## 现状
终端 → SFTP 已有（打开 SFTP 时 alignCwd 对齐 pwd）；SFTP → 终端缺失，只能复制路径再手敲 cd。

## 设计
- 远端路径栏"复制路径"旁新增"在终端进入"（仅远端窗格，testid sftp-cd-terminal）。
- 找到同一会话、已连接的终端标签，切过去，用 cdCommandFor 生成 ` cd -- '<path>'`（前导空格不进 history、单引号转义），**填入不执行**：终端里可能正跑着程序，回车留给用户。
- 无已连接终端时提示，不做任何写入。
