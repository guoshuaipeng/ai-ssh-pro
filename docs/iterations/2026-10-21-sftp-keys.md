# D55 SFTP 键盘操作补缺（2026-10-21 第 25 轮）

## 核对
- 已有：Enter 打开（目录进入、远端文件打开编辑器）、Ctrl+Enter 上传或下载、Backspace 上一级、F5 刷新、F2 重命名、Tab 切换窗格。
- Delete 已有确认：removeEntry 先走写入保护，再弹 confirmDialog（danger，写明远端删除不可恢复）。
- 缺口：
  - ↑/↓ 不能移动选中，只能用鼠标点，所以前面这些键实际只对第一行或已经点选的行生效。
  - Enter 打开远端文件时绕过了 D36 的大文件和二进制判断。

## 方案
- ↑/↓ 移动选中项，Shift+↑/↓ 扩展选择，选中行自动滚进可见区域。
- 双击和 Enter 都走 openRemoteEntry：二进制文件只提供下载，大文件可以下载或「仍然打开前 2 MB」。
- Delete 行为不变，仍然需要确认。
