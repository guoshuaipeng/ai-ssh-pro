# D54 终端右键「复制上一条命令的输出」（2026-10-21 第 25 轮）

## 核对
- 分块视图（TerminalBlocks）每块已有「复制输出」，但分块默认关闭，大多数人用不到。
- D22c、D22d 已在内存里按会话滚动记录输出（开 Shell Integration 后才有），平时只用于失败捕获。

## 方案
- 命令结束（OSC 133 退出码）时，把 capturedOutput 的结果存进 lastRuns：去掉回显的命令行，末尾留白去掉，最多 8000 字符。
- 终端右键新增「复制上一条命令的输出」，没有记录时置灰。复制后提示是哪条命令的输出。
- 只存在内存里，不写盘。敏感命令本来就不记录（captureStart 和 captureCommand 都已排除），所以也没得复制。
- 复制到用户自己的剪贴板，不做脱敏，和手动框选复制一样。
