# D76 SFTP 远程工具栏收拢

核对：c31 截图里，1024 宽度下远程工具栏换成了两行，原因是 D71、D75 新加了按钮 → 真实问题。
设计：
- 远程面板的「新建目录」「新建文件」合并为一个「新建 ▾」按钮，点开是菜单。
  - 菜单复用 openContextMenu，贴在按钮下方。
  - 只读主机、写入被拦截时，整个按钮禁用。
- 「子目录搜索」改成搜索图标按钮，提示文字和无障碍名称（aria-label）不变。
- 「显示隐藏文件」两侧都改成 .* 开关（aria-pressed），提示文字不变。
- 本机面板仍保留「新建目录」文字按钮。
- e2e 测试改为先点「新建 ▾」，再点菜单里的「新建目录」；test-cycle30 的断言同步更新。
结果：c32 截图里，1024 宽度下两侧工具栏都只有一行。
