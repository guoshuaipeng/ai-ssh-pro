# D108：「全部标签」打不开（2026-10-21）

## 根因
按钮在有标签时始终显示，但有一个 effect 写成「标签栏未溢出且列表已打开 → 关闭」。标签较少、标签栏未溢出时，点击按钮刚打开列表，同一轮渲染后这个 effect 就把它关掉，看起来像是闪一下。与 mousedown 时序无关：点击外部关闭已经排除了按钮和挂到 body 上的列表。

## 修复
只在标签栏从「溢出」变为「不溢出」的那一刻关闭（用 ref 记录上一次状态）。

## 按钮
文字按钮「全部标签 ⌄ N」改为图标按钮，与分屏模式按钮同尺寸、同样式；右上角小角标显示标签总数（有标签被滚出视野时角标为强调色）；tooltip 为「全部标签（N）」；aria-label 仍包含未显示数量。
