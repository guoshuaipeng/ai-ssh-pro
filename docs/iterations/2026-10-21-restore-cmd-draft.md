# D63 会话恢复补全：命令栏草稿

核对：
- 「上次会话」已保存各终端的工作目录（D8 / 8d31fb7）。重连后回到原目录，未连接的标签用 restoreCwd 兜底；D20b 本地 shell 也覆盖了。不重复做。
- 命令栏草稿（D24）只在内存里，重启后丢失 → 这是唯一的真实缺口。
设计：
- 保存工作区时，每个终端标签带上当前草稿。条件：单行、不超过 500 字符、不是敏感命令（isSensitiveCommand），并且脱敏前后完全一样，含疑似密钥的一律不存。
- 恢复时用新的 tabId 预填回命令栏，只填入，不执行。
- startup-pref 读取时会再校验一遍。
