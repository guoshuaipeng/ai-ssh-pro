# D10 按命令分块的输出：复制 / 问 AI · P1（高频）

## 先盘点已有功能
- 已有：命令分块条（M2，默认关闭）。每块有折叠、AI 解释、复制命令、存为片段，可以拖动调整高度。
- 缺口：
  1. 只有命令栏发出的命令才会生成分块，用户直接在终端里敲的命令不会。
  2. 不能单独复制某条命令的输出。
  3. 不能带着这段输出接着问 AI。
  4. 分块条被终端挤出可视区，实际看不到（布局 bug，这次一起修了）。

## 需求 / 验收
1. 在终端提示符下按回车时，取当前行的命令开始一个新分块：
   - 能识别 `user@host:/path# ` 这类 bash 提示符，以及 `$ / # / % / ❯` 结尾的提示符。
   - 全屏程序（alternate buffer）里、空行、密码提示时都不生成分块。
2. 每块新增“复制输出”：没有输出时禁用，并在悬停时说明原因。还新增“问 AI”：复用 D6，把 `$ 命令` 加上输出结尾的 4000 字符填进当前标签的对话输入框，不自动发送。
3. 布局修复：`.terminal-layer` 里有分块条时改成纵向 flex 排列，终端占剩余空间，分块条保持设定的高度。
