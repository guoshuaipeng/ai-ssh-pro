# D13d 快速连接 / 「最近」的密码主机

**PM**：临时连接默认先用密钥 / agent；密码主机认证失败后要打开完整编辑器重填。「最近」里未保存的普通行也会打开编辑器。

**方案**
- 快速连接（含 Ctrl+P、侧栏地址搜索、「最近」中所有未保存的行）认证失败、且未指定 `-i` 密钥时，弹出小对话框「输入 user@host 的密码」（密码框不回显），说明"密码仅用于本次连接，不会保存；如需长期使用，请「保存为主机」"。
- 确认后在同一标签页重连；密码错误可再输入，最多 3 次；取消则保持断开状态，可走原有重连 / 编辑。
- 密码只存在该标签页的内存连接参数中；工作区快照只保存白名单字段，不包含密码。
- 网络不可达等非认证错误不弹密码框。
