# D30 SFTP 窄宽度路径栏（2026-10-20，第 18 轮）

## 问题（第 17 轮截图发现）
双栏 SFTP 每个窗格约 400px，路径栏是单行不换行的 flex：面包屑、路径输入框、文件名筛选被压成空白小框，远端只剩"/ 复制"。

## 修复
- 路径栏允许换行（row-gap 4px）：面包屑最少 8rem、路径输入框最少 9rem，放不下时操作按钮（刷新/新建目录/筛选/排序/隐藏文件）自动折到第二行；宽窗格仍是一行。
- 根目录面包屑"/"后不再多画一个分隔符（原来显示"/ / home"）。
- 纯 CSS + 一处渲染判断，不改交互。
