# D7b 多行粘贴：本主机不再询问 + 括号粘贴检测

**PM**：D7 预览对常贴脚本的人太打扰；但生产机必须一直拦。

**现状核查**：D7 对所有多行粘贴都弹预览，无偏好、不看远端模式。

**规则（`shared/paste-skip.ts` pasteDecision）**
1. 单行 → 直接粘贴。
2. 生产 / 只读主机（含会话只读）→ 始终预览，不显示"不再询问"，改显示"生产 / 只读主机：多行粘贴始终需要确认"。
3. 含危险行 → 始终预览（勾了"不再询问"也一样）。
4. 普通主机：勾了"本主机不再询问"或远端开启括号粘贴（xterm `modes.bracketedPasteMode`，bash ≥5.1 / zsh 默认开）→ 直接粘贴。括号粘贴下多行整体进入提示符，按回车才执行，不会逐行跑。
5. 其余 → 预览。预览里括号粘贴时提示文案替换为对应说明。

**数据**：`aiss.paste.skipHosts.v1`（hostKey 列表，最多 200）；严格主机集合由 App 按标签保护级别推给 `lib/paste-pref`。

**限制**：暂无设置页入口清除"不再询问"；危险粘贴仍会弹出预览，可在那里取消勾选。
