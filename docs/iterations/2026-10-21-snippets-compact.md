# SN2：片段面板紧凑列表与内置片段扩充（2026-10-21）

## 问题
内置片段只有 3 条；每条是很高的卡片（标题、徽标、说明、三个文字按钮），一屏只能看到几条。

## 内置片段
扩充到 26 条，全部为日常运维的只读或低风险命令，按类别打标签：系统、磁盘、内存、进程、网络、日志、Docker、服务。不含删除、重启、启停服务、kill 等命令（`test-snippets-compact` 以正则校验）。带参数的片段使用已有的 {{变量}} 机制（如 {{port}}、{{dir}}、{{service}}、{{container}}、{{url}}、{{domain}}、{{keyword}}），注入前弹出填写框。docker 自带的 {{.Names}} 模板不会被当作变量。标题、说明与标签均为中英双语。原有 3 条的 id 不变。

## 列表
- 每条一行：标题 + 「内置」徽标 + 类别，右侧为等宽灰色、截断显示的命令；悬停显示完整命令与说明。
- 「注入 / 预览 / 另存为」（内置）以及「注入 / 注入并执行 / 编辑 / 删除」（我的）改为图标按钮，仅在悬停、键盘选中或聚焦时出现。
- 双击整行即注入，只填入不执行；预览仍可通过图标按钮打开。
- 列表可聚焦，↑ / ↓ 选择，回车注入；输入法组字期间不响应。
- 搜索匹配标题、命令、说明与类别；「全部 / 内置 / 我的」筛选保留。
