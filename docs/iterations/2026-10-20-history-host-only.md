# D38 Ctrl+R「仅当前主机」开关（2026-10-20 第 20 轮）

## 现状
- Ctrl+R 已把当前主机的历史排在前面，后面跟着其他主机的历史和片段。命令栏联想也是当前主机优先。
- 缺口：同时用多台主机时，其他主机的命令混在列表里，没法只看本机。

## 方案
- rankHistoryPick 加 hostOnly 参数：只保留当前主机的条目，片段也不显示；没有当前主机（hostKey 为空）时不生效。
- Ctrl+R 输入框下方加「仅当前主机」按钮，Alt+H 也能切换，状态记在 localStorage 的 aiss.qp.hostOnly。
- 只在有当前主机时显示这个按钮。命令栏联想不改，它本来就是当前主机优先。
