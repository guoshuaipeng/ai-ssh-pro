# D60 跨标签搜索终端输出

需求：同时排查多台主机时，同一条报错要在好几个标签之间来回找。
核对：现有查找（D19）只搜当前标签，没有跨标签搜索 → 真实缺口。
设计：
- 每个终端面板把自己的缓冲读取函数登记到 lib/term-buffers（只在内存里，按需读取）。
- 入口有三处：Ctrl+Shift+Alt+F、菜单「搜索所有终端标签…」、命令面板。
- 弹窗打开时对各标签缓冲拍一次快照，按不区分大小写的子串匹配；每个标签内从新到旧排列，最多显示 200 条。
- ↑/↓ 选择结果，回车或点击切到对应标签，并把关键词填进该标签的查找栏、定位到匹配处。
- 只读，不写任何文件。
