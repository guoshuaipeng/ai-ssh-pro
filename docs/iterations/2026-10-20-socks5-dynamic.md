# C1 SOCKS5 动态转发（-D）· P0

## 需求
- 问题：要用浏览器或 CLI 通过跳板访问内网的很多地址时，一条条配 -L 转发太繁琐。
- 用户故事：作为运维，我想在本机开一个 SOCKS5 端口，让任意目标都经由当前 SSH 会话出去。
- 验收：
  - 端口转发弹窗新增“动态 -D”模式，只需填写本地端口。
  - 仅监听 127.0.0.1，支持 NO AUTH 与 CONNECT（IPv4、域名、IPv6）。
  - 不支持的命令回复 0x07，不支持的地址类型回复 0x08，目标连接失败回复 0x05。
  - 列表显示最近一次连接的目标，可以复制 `socks5h://127.0.0.1:port`。
  - 每次建立都写入审计 `forward.dynamic`；重连后自动恢复。
  - 只读主机也允许使用，因为 -D 不改变服务端状态。

## 交互 / UI
- 分段控件依次为：本地 -L / 远程 -R / 动态 -D。选择 -D 时隐藏远程主机和远程端口字段。
- 列表中的徽标显示 `-D`。“远程”列显示最近一次的目标，还没有连接时显示“任意（SOCKS5）/ Any (SOCKS5)”。
- 复制按钮的文案为“复制代理地址 / Copy proxy URL”。
- 空状态与错误状态沿用 -L 的样式。端口被占用时显示行内错误。没有加载态。
- 颜色与间距使用 `--color-accent`、`--space-2` 等 token。

## 实现
- 协议解析：`src/shared/socks5.ts`。
- 转发：`forward-manager.ts` 中的 `startDynamicForward`。
- 测试：`scripts/test-socks5.ts`。
