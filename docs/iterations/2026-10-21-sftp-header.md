# SH1：SFTP 双栏窗格头部改版（2026-10-21）

## 问题
面包屑与路径输入框重复；左右窗格结构、按钮顺序不一致（左三行、右两行）；文字按钮过多；筛选与搜索两个入口；盘符为原生下拉。

## 设计
- 每个窗格头部统一为一行，左右完全对称：窗格名 ·（本机）盘符 · 地址栏 · 工具组。窄宽度下不折行，地址栏收缩。
- 地址栏（资源管理器风格）：平时显示可点击的面包屑；点击空白处或按 Ctrl+L / Alt+D 进入输入状态，回车跳转，Esc 取消。取消「转到」按钮（保留隐藏的同名入口供自动化与读屏使用）。
- 工具组全部为图标按钮并配 tooltip，顺序固定：上级、刷新、新建（远程为「新建」菜单：目录 / 文件）、最近、筛选、排序、更多。
- 「更多」菜单：复制路径、输入路径、在终端进入（远程）、在子目录中搜索（远程）、显示隐藏文件（带 ✓）。
- 筛选与搜索合并为一个入口：点击筛选图标展开筛选行，输入即按名称筛选；远程额外提供「在子目录中搜索…」。有筛选词时图标高亮并保持展开，Esc 清空并收起。
- 盘符改用主题 Select（原生下拉计数 38 → 37）。
- 紧凑模式下仍可收起或展开地址栏。

## 保留
所有原有功能、testid、快捷键（窗格内键盘导航、Ctrl+A、键入跳转等）不变。顶部全局一行（打开到会话目录、对比 / 同步、跟随终端、紧凑、传输队列、高级）本轮未调整，列入后续。
