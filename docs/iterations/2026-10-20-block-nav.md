# D15 命令块键盘导航 + 重新执行

**PM**：回看上一条输出、重跑命令是终端里最频繁的动作，分块现在只能用鼠标。

**现状核查**：分块只有鼠标点选，Ctrl+Shift+E 解释；没有跳转、没有重跑。

**交互**
- 终端里 Ctrl+↑ / Ctrl+↓：跳到上一条 / 下一条命令开始的位置（xterm marker，每条提交的命令记一个），分块条同步选中并滚到该块。全屏程序（vim/less，备用屏）里不拦截。到底后 Ctrl+↓ 回到最底部。
- 分块条里 ↑/↓ 在块间移动焦点，Enter = 重新执行。
- 「重新执行」按钮：把命令放回该会话命令栏，提示"按回车执行"。**不直接写入**——回车走命令栏原有的主机保护 / 危险命令确认，所以生产机、只读会话的规则不变。

**测试**：test-cycle8 D15 ×2；截图 `blocks-nav.png`。

**限制**：marker 不分块开关，始终记录；不开分块也能用 Ctrl+↑/↓。
