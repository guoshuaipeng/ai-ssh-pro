# D31 历史命令记住执行目录（2026-10-20，第 18 轮）

## 需求
Ctrl+R / 命令栏联想显示命令上次在哪个目录执行，并可一键"在原目录"重放，避免相对路径命令跑错地方。

## 设计
- 数据：HistoryEntry.lastCwd（posix 路径，≤1024），在命令**开始时**取会话 cwd（命令栏提交时 / Shell 集成 E 上报时——此时 OSC 7 尚未更新，正是执行前目录），退出时与退出码一并写入（withCwd）。cd/pushd/popd 本身不记目录。
- 展示：Ctrl+R 行右侧灰色显示目录；命令栏联想 meta 同样显示。
- 动作：目录与当前会话目录不同时，Ctrl+R 行显示"在原目录"，填入 `cd -- '<dir>' && <cmd>`（不加前导空格，命令本身仍进 shell history），**不自动执行**。
- 目录来源与 D2 相同（OSC 7 / bash 提示符），只记 posix 路径；Windows 本机路径不记录。
