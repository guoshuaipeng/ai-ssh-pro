# D41 终端选中路径 → 在 SFTP 中打开（2026-10-20 第 21 轮）

## 现状
- SFTP 到终端方向已有：在终端进入（D28）、回到终端目录。终端右键「SFTP」会按终端当前目录打开。
- 缺口：终端输出里看到一个路径（ls、日志、报错信息里的路径），想在 SFTP 里看，只能手动输入。

## 方案
- 终端右键新增「在 SFTP 中打开选中路径」，选中内容不像路径时置灰。
- shared/term-path.ts 的 pathFromSelection 负责识别：
  - 支持绝对路径、~ 开头的路径，以及 ./、../ 或带 / 的相对路径（按终端当前目录解析）。
  - 去掉末尾标点和引号。
  - 网址、带空格、多行的选中内容不当成路径。
- lib/sftp-goto.ts 先把目标记下，再按现有方式打开或聚焦 SFTP 标签。
  - SFTP 面板首次打开时，优先用这个目标，其次才是终端目录。
  - 已经打开的面板通过事件收到目标后直接跳转。
- ~ 用 sftp.home 展开。目标无法列出（是文件或不存在）时，打开所在目录并提示。
- 只读操作，不涉及写入和执行。
