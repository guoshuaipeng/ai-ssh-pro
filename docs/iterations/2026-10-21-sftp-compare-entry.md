# D62 SFTP 同步入口与较新一侧提示

核对：D2「文件夹同步」已经能对比、勾选和显式同步，删除默认关闭，生产主机删除要输入主机名。但还有两个缺口：
1. 入口藏在「高级」里；
2. 「修改」的文件不区分哪一侧更新，默认全部勾选，可能会用旧文件覆盖目标端更新过的文件。
设计：
- 工具栏「打开到会话目录」旁边新增「对比 / 同步」按钮，打开同一个对话框；「高级」里的原入口保留。
- diffTrees 对「修改」行标记 targetNewer（目标端 mtime 比源端新 1 秒以上）。这类行显示「目标较新」，默认不勾选，要手动勾选才会覆盖。
- 本轮不做同一次对比里的双向同步。原因是要处理冲突，两端都改过的文件需要单独设计；先用方向切换加「目标较新」提示保证安全。删除仍默认关闭。
