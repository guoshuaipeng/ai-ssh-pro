# D101 同名标签自动编号 / D103 会话标签悬停显示地址与状态

- **问题**：用户截图里同一台主机开了多个会话，或者复制了会话，标签栏里会出现好几个一模一样的「演示主机 (demo)」，分屏副屏的下拉框里也一样，分不清哪个是哪个。会话标签的 tooltip 只有「固定」提示，看不到 user@host:port 和连接状态。
- **去重**：grep docs/iterations 与 src（dupTitle / disambig / 同名标签）均无结果；tooltip 里的地址目前只有 SFTP 标签有（sftpAddr）。
- **D101**：
  - shared/tab-dedupe 按标签条的顺序给同名标签编号。第一个保持原名，之后的在名字后面加一个弱化的「· 2」「· 3」。
  - 编号只用于显示，不改动用户自定义的标题。
  - 分屏的主屏标题和副屏下拉选项使用同样带编号的名字。
- **D103**：会话标签的 tooltip 改为「名称：user@host:port（已连接 / 连接中 / 已断开）」，保留原来的保护、断开原因和固定提示。

# D102 双击标签栏空白处新建连接
- **问题**：标签开多以后，「新建连接」在标题栏另一侧，要移动鼠标过去。浏览器、Windows Terminal 等常用软件都支持双击标签栏空白处新建，用户会下意识这样操作，但目前没有反应。
- **去重**：grep 双击空白 / tab-bar-scroll onDoubleClick 无结果。
- **方案**：在标签条的空白处双击，走现有的「新建连接」动作。双击标签本身仍是重命名，两者不冲突。空白处悬停时有提示说明这个操作。
