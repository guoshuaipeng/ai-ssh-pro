# D22 命令历史：按主机优先 + 失败标记

**现状核查**：Ctrl+R 选择器已是"本主机优先"（D3）；命令栏 ↑/↓ 仍走全局历史，不分主机；历史条目不记录执行结果。

**方案**
- 命令栏 ↑/↓：先按时间倒序走**本主机**命令，再接全局历史（去重）。智能历史关闭时行为不变。
- 失败标记：命令结束能拿到退出码时（分块 + 退出码捕获，或 Shell Integration），把退出码记到该主机该命令的历史条目上；再次成功执行即清除。
  - Ctrl+R 列表与命令栏联想中，上次失败的命令显示红色「上次失败 n」，悬停说明；同等匹配下排在成功命令之后（不隐藏）。
- 不记录敏感命令（沿用现有过滤），只存退出码，不存输出。
