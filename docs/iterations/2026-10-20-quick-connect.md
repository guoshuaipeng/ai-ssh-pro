# D13 快速连接（user@host:port / 粘贴 ssh 命令）

**PM**：临时连一台没保存的机器是每天都有的动作，现在要先打开表单填 4 个字段。

**现状核查**：只有"最近连接"的快速连接（按 host/user/port 找已保存主机，否则预填表单）；Ctrl+P 只能搜已有标签和主机，不识别地址；没有 ssh 命令解析。

**交互**
- Ctrl+P 输入 `ops@10.0.0.5:2222`、`[fe80::1]:2200`、`10.0.0.5`、`web.example.com` 或粘贴 `ssh -p 2222 -i ~/.ssh/k -J ops@bastion u@h`，列表第一项变成「连接 u@h:2222」，副标题显示 -i / -J / 是否已保存。
- 普通搜索词（如 `nginx`，不带 @、端口、点号）不会触发，Ctrl+P 原有行为不变。
- 选中：匹配到已保存主机 → 直接连接；否则打开预填好的连接表单（主机、端口、用户、密钥路径、跳板链），提示"补全密码或密钥后连接"。不会在没有凭据的情况下盲连。

**解析**（`shared/quick-connect.ts`）：-p -i -J（逗号多跳，≤5）-l、-o Port/User/IdentityFile；其他带参数的选项会被跳过；目标之后的内容按远程命令忽略；端口 1–65535、IPv4 段 ≤255 校验。
