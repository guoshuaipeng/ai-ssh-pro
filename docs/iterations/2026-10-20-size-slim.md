# 2026-10-20 · 安装包瘦身（路线图 1.5）

## 一、需求（PM）

- **问题**：Windows 安装包由 v0.6.36 的 85.7 MB 涨到 v0.6.63 的 168.6 MB，下载时间翻倍；原因见 `docs/size-audit-0.6.63.md`。
- **用户故事**：作为首次下载的用户，我希望安装包和同类工具相当（≤ 110 MB），在慢速网络下也能较快装好。
- **验收标准**
  1. 实际打包（`electron-builder --win`，不发布）的 NSIS 安装包 ≤ 110 MB，并记录前后实测大小。
  2. 中文（Noto Sans SC 400/500/600）、英文（Inter 400/500/600）、等宽（JetBrains Mono 400/500）字体在构建产物中仍然加载（`document.fonts.check` 为真）且截图正常。
  3. 打包后的 `win-unpacked` 可正常启动。
  4. 有单元测试锁定：字体包不得回到 `dependencies`；`electronLanguages` 只含 zh-CN / en-US；woff 回退被移除且每个 `@font-face` 仍有 woff2。

## 二、交互与界面（设计）

本项无界面变化。设计侧要求：字体视觉不得变化（同字族、同字重），界面语言只提供中文、英文，与应用已有的两种语言一致；Chromium 的系统对话框（如右键「检查」等少数原生文案）在其他系统语言下会退回英文，可接受。

## 三、实现（开发）

| 措施 | 做法 |
|---|---|
| 字体包移出运行时依赖 | `@fontsource/inter`、`@fontsource/jetbrains-mono`、`@fontsource/noto-sans-sc` 移到 `devDependencies`；渲染进程字体仍由 Vite 打包进 `out/renderer/assets` |
| 只保留 woff2 | `electron.vite.config.ts` 增加 `fontsource-woff2-only` 插件，调用 `src/shared/fontCss.ts` 的 `stripWoffFallback()`，删掉 `@font-face src` 中的 woff 回退；同一条 src 没有 woff2 时不动 |
| 裁剪 Chromium 语言包 | `build.electronLanguages: ["zh-CN", "en-US"]` |
