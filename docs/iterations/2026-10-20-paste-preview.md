# D7 多行粘贴预览与确认 · P1（高频、高风险）

## 需求
- 问题：粘贴多行内容时会立刻逐行执行，误粘到生产机上很危险。
- 验收：
  1. 所有粘贴入口都会先判断：Ctrl/Cmd+V、Ctrl+Shift+V、Shift+Insert、右键“粘贴”、“粘贴并执行”、原生粘贴事件。只要有超过 1 行非空内容，就先显示预览。单行内容照常直接粘贴。
  2. 预览显示总行数（最多列出 12 行，其余显示“还有 N 行未显示”）。高危行用 `--color-warn` 标出，悬停显示原因（复用 command-risk 的规则）。另外提示是否每一行都会立即执行（看末尾有没有换行）。
  3. 按钮：
     - 取消：有高危行时默认聚焦这个按钮。
     - 合并为一行（&&）：内容包含 heredoc、续行、注释或以管道结尾时禁用，并悬停说明原因。
     - 全部粘贴：没有高危行时默认聚焦。
  4. 按 Esc 取消，焦点回到终端。
  5. 粘贴仍然走 paste → onData，只读拦截照常生效。镜像（只显示）终端不弹预览。代码片段的注入是用户主动操作，不经过预览。

## 交互 / UI
- 浮层放在终端内部，水平居中。使用 `--color-bg-surface`、`--shadow-menu`、`--radius-sm`，代码使用 `--font-mono`、`--fs-xs`。没有加载态。
