# D19 分块搜索与终端 Ctrl+F 合并为一个入口

**PM**：D17 在分块条里加了独立搜索框，和终端 Ctrl+F 查找栏是两个入口、两套选项，用户不清楚该用哪个。

**现状核查**：终端查找栏（Ctrl+F，支持大小写 / 正则 / 上下跳转 / 计数）；分块条另有搜索框（只支持不区分大小写的包含）。

**方案**
- 统一入口为 **Ctrl+F 查找栏**。分块开启时，查找栏左侧出现范围切换「终端 | 分块」；分块关闭时不出现，行为与以前完全一致。
- 「分块」范围：同一个输入框、同一套 Aa / .* 选项；分块条只显示匹配的分块并展开输出；回车 / Shift+回车（或 ↑↓）在匹配分块间跳转并选中；计数显示「n 个分块」或「i/n」。
- 关闭查找栏（Esc）或切回「终端」即清除分块过滤。
- 分块条头部原搜索框改为按钮「搜索分块」，点击直接打开查找栏并切到「分块」；过滤中显示可点击的提示「“sda” · 1 个匹配」。
- 上次使用的范围会被记住（`aiss.find.scope`）。
