# D16 AI 回答中的命令 → 命令栏 → 结果一键发回 AI

**PM**：问 AI 为何失败（D11）之后，下一步一定是执行它给的修复命令，再把结果贴回去。现在要复制、粘贴、再复制输出。

**现状核查**：AI 回答里的代码块只有「复制」；结构化命令卡片（A1 运行）已有执行通道，但普通回答里的 ```bash 块没有。

**交互**
- 回答里单行 shell 代码块（bash/sh/zsh/shell/console/无语言；去掉 `$ ` 前缀；注释行忽略）多一个「填入命令栏」。多行脚本、heredoc、续行、其他语言不显示，避免半截执行。
- 点击：放进当前会话命令栏，**不自动执行**；回车走命令栏原有的保护/危险确认。
- 执行后对应输出分块多一个「结果发回 AI」（强调色），把命令 + 退出码 + 输出尾部 + "下一步怎么做？"预填进该标签的 AI 对话（D6 的同一会话），用户确认后发送。
- 未开启输出分块时，填入后提示开启方法。

**开发**：`shared/ai-fill.ts`（fillableCommand / createOriginSet），`lib/ai-origin.ts`；AIPanel AiCodeBlock；TerminalBlocks。
