# D51 SFTP 传输完成提示带下一步（2026-10-21 第 24 轮）

## 核对
- 传输队列每一行已有「打开所在文件夹」（sftp-xfer-reveal）按钮，但队列常常是折叠的，传完没有任何提示。

## 方案
- 队列里没有排队中或进行中的任务时，弹一次提示，不会每个文件都弹：
  - 只传了一个文件时显示「已下载 / 已上传 {name}」，传了多个时显示「N 个文件传输完成」。
- 提示上的操作按最后一个任务的方向决定：
  - 下载：「打开所在文件夹」，调用 localFs.reveal，只是打开文件夹，不运行文件。
  - 上传：「在终端进入」，复用 D28，只把 cd 到远端目录的命令填进终端，不执行。
