# D20 重连恢复（与 D2 重叠核查）

**核查结论：D2 已覆盖 SSH 重连回到原工作目录，D20 缩减为"分块状态"补漏。**

- 所有 SSH 重连入口（手动重连、自动重连倒计时、冷启动恢复、跳板重试、批量重连）都调用 `reconnectTab`；`window.aiss.ssh.connect` 全仓只有 `openSession` 和 `reconnectTab` 两处，后者在成功后发送 `cd <原目录>`（D2，0d4c82f）。已加测试锁定这一点。
- 未覆盖的路径：**本地终端（local shell）重连**直接返回、不恢复目录。本地终端在 Windows 上是 PowerShell，D2 的 POSIX 引号规则不适用，且使用频率低，本轮不处理，记入 backlog。
- 分块状态：分块条按标签页挂载（key=tabId），重连后分块本身**不会丢失**；缺口是断线时正在运行的分块永远停在「运行中」。

**方案**：会话 ID 变化（重连）时，把运行中的分块标记为「已中断」（灰色徽标，悬停说明"执行期间连接断开，输出不完整"），其余分块不变。

**测试**：test-cycle12 D20 ×2。
