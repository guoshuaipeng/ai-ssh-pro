# D8 重启后恢复上次的标签与目录 · P0（高频）

## 先盘点已有功能
- 已有 UX-50：可以选择“恢复上次布局 / 上次会话”。会恢复终端、SFTP、监控等标签及其顺序、置顶和当前标签，缺失的主机会跳过并提示；只有“上次会话”会自动连接。
- 缺口：恢复的终端连上后停在家目录，丢了上次所在的工作目录。所以本项只补这一点。

## 需求 / 验收
1. 保存工作区时，每个终端标签多存一个 `cwd`，来源是 D2 的实时记录；如果还没连接过，就用上次恢复出来的值。保存时机：标签变化时，以及窗口关闭时（beforeunload）。
2. 读取时，只接受能安全生成 `cd` 的路径（与 D2 的规则相同）。家目录、相对路径和带控制字符的路径会被丢弃。
3. 恢复出来的终端第一次连接成功后写入 ` cd -- '<path>'` 并提示；之后的重连仍使用实时 cwd。
4. 不保存任何凭据，也不重放任何用户命令。生产或只读主机同样只做切换目录。

## UI
- 不新增控件。沿用 D2 的 toast：“已回到工作目录 {path}”。
