# D74 核对 / D75 替补：SFTP 子目录搜索

D74 核对：已覆盖，不重复做。
- AI 回复里的命令块本身带风险等级标签（shell · 风险: low / medium）。
- 用「填入」放进命令栏后，SessionCommandBar 的 explain（D16d）会显示风险提示和危险样式。
- 发送时，SafetyCommandBar（D48）会再做一次本地风险评估，并确认一次。

替补 D75：PM 复查 SFTP 浏览路径。
- 现状：「筛选文件名」只筛当前目录。找 /etc 或项目目录深处的配置文件，只能一层层点进去，或者回终端执行 find。
- 结论：真实缺口。
设计：
- 远程面板新增「子目录搜索」，弹窗里输入文件名的一部分，按回车开始搜索。
- shared/sftp-tree-search 的 searchTree 只靠 SFTP 列目录做广度优先遍历，不在服务器上执行任何命令。限制如下：
  - 最多 5 层、400 个目录、200 条结果；
  - 跳过 .git、node_modules 等目录；
  - 不跟随符号链接目录。
- 结果没扫完时会说明，建议进入更深的目录再搜。
- 选中结果后只做定位：打开所在目录并选中该文件；如果结果是目录，就直接进入。
