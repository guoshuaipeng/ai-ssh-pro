# D25 新开本机终端沿用当前标签目录（2026-10-20，第 16 轮）

## 需求
在本机终端标签里新开本机终端时，直接在同一目录打开，不必再 cd。

## 设计
- 与 Windows Terminal / iTerm 的"新标签继承目录"一致：当前活动标签是本机终端且已知目录（OSC 7、bash 或 Windows 提示符，D20b）时，openLocalShell 带上该目录；其他情况仍从主目录开始。
- 复用 D20b 主进程校验 localStartCwd（绝对路径、存在的目录，否则主目录）。
- 提示语注明打开位置，用户能立刻看出没在主目录。
- 不从 SSH 标签继承（远端路径在本机无意义）。

## 不做
不新增设置项：仅在本机标签内新开时生效，影响范围小；如需主目录可 `cd ~`。
