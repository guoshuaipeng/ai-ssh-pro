# D9 SFTP 传输体验 · P0（高频）

## 先盘点已有功能
- 已有：
  - 失败、中断、暂停的条目都有“继续”按钮，按 offset 续传，写入 `.aisshpart` 后再改名。
  - 源文件变化时会提示重新传输。
  - 有“自动续传”开关，可以“清除已完成”。
  - 可以拖拽到 SFTP 远程窗格上传。
- 缺口：
  1. 多个条目失败时，只能一个个点继续。
  2. 把文件拖到终端上不会有任何反应。

## 需求 / 验收
1. 队列头部新增“全部重试（N）”，只在有失败或中断条目时显示。点击后按顺序逐个续传，过程中按钮禁用，悬停有说明。
2. 把本地文件拖到终端：
   - 显示虚线覆盖层“松开以上传到 {dir}”。dir 取 D2 记录的 cwd，没有记录时用 `~`。
   - 松开后打开该会话的 SFTP（已经打开就聚焦），文件进入上传队列，目标目录是 `dir`。`~` 会解析成 SFTP 的家目录。
   - 提示“已加入上传队列：N 个文件 → dir”。
3. 只读主机：拖放时直接提示“不能上传”，SFTP 原有的写入门禁也照常生效。镜像终端不响应拖放。
4. 拖动中途取消时，覆盖层在 0.8 秒内自动消失。

## UI
- 覆盖层使用 `--color-accent` 虚线边框、`--color-accent-muted` 底色，`pointer-events: none`。没有加载态。
