# D84 复制可直接运行的 ssh 命令

- 去重：已有「复制连接串」（命令面板，user@host:port）和侧栏「复制 user@host」（拼成 `user@host -p 端口`，不能直接运行，也没有跳板机）。所以只补不足的部分，不新建菜单。
- 方案：shared/connection-string.ts 新增 formatSshCommand，输出 `ssh [-p 端口] [-i 私钥路径] [-J 跳板1,跳板2] 用户@主机`。
  - 只有在密钥认证时才带 -i；不含密码或私钥口令；路径里有空格时用单引号括起来。
  - 侧栏菜单项改名为「复制 ssh 命令」，改用新格式；标签右键也加同一项（本地终端和演示主机不可用）。
  - 生成的命令可以被快速连接（D13c）直接粘贴解析。
