# D72 终端里的路径可点击

核对：
- D41 已有「在 SFTP 中打开」，但要先选中文字再右键，步骤多。
- 现有的链接识别（D70）只认 http(s)。
- 结论：路径不能直接点击，这是真实缺口。
设计：
- shared/term-links 新增 findPaths，识别以下几类路径：
  - 绝对路径
  - ~/ 开头
  - ./ 或 ../ 开头
  - 含斜杠的相对路径
- 编译器输出里 file.ts:12:3 这样的行号列号会被算进可点范围，定位时去掉。
- 以下内容不会被当成路径：URL 片段、纯数字和标点组成的串（日期、分数、版本号）。
- 交互方式：
  - 按住 Ctrl 点击：用 pathFromSelection 把路径解析成绝对路径，再通过 requestSftpGoto 在 SFTP 定位，只定位不执行。
  - 普通点击：保持原来的选中行为，不弹提示，避免路径太多造成干扰。D70 的提示文字里顺带说明了路径的用法。
- 相对路径要知道当前目录才能解析；不知道时提示需要开启 Shell 集成。只镜像的终端不启用。
