# D5 远程文件编辑：自动保存 + 远端改动冲突提示 · P0（高频）

## 需求
- 现状：内置编辑器可以“保存到服务器”（可选先看差异、写 .bak、存快照），但保存前不检查远端文件，可能覆盖别人在此期间的改动。也没有自动保存。
- 验收：
  1. 每次保存前重新读取远端内容，并与打开时（或上次保存时）的基线比较。不同就停下来，显示冲突条：
     - “查看差异”：显示远端当前内容与我的修改之间的差异。
     - “仍然覆盖保存”。
     - “放弃我的修改并载入远端版本”。
  2. 远端内容被截断（大文件）时无法比较，不报冲突。
  3. “自动保存”复选框默认关闭，设置记在本地。停止输入 1.5 秒后保存，不弹差异预览。遇到冲突、截断、只读、正在保存或加载时都不自动保存。
  4. 只读主机上“自动保存”和“覆盖”都禁用，悬停显示原因（l4.readonlyBlocked）。原有的写入门禁（beforeRemoteWrite）照常生效，生产主机每次保存仍要确认。
  5. 状态栏显示“已自动保存 HH:MM:SS”。

## 交互 / UI
- 冲突条：`--color-warn-muted` 底色，放在状态栏下方，`role=alert`，按钮从左到右依次是 查看差异 / 覆盖 / 放弃。
- 差异图例：“− 远端当前内容　+ 你的修改”。在冲突差异视图里，主按钮文案变为“仍然覆盖保存”。
- 没有新增加载态（编辑器原有的“读取中”保持不变）。
