# D56 侧栏 ↑/↓ 选主机 + D57「复制上一条命令的输出」命令面板与快捷键（2026-10-21 第 26 轮）

## D56
- 核对：侧栏列表已有 Enter 打开、F2 重命名、Delete 删除（有确认），但不能用 ↑/↓ 在主机间移动。D53 用 ↓ 进入列表后只能选中第一条。
- 方案：主机行加 data-profile-id。侧栏列表按 DOM 里的显示顺序（已包含文件夹展开状态和过滤结果）用 ↑/↓ 移动选中，并滚进可见区域。

## D57
- 核对：D54 只有终端右键菜单这一个入口。
- 方案：
  - 菜单和命令面板新增「复制上一条命令的输出」（copyLastOutput，拼音别名 fuzhi shuchu）。
  - 快捷键 Ctrl+Shift+Y：核对过 KEYMAP，这个组合没被占用；作用范围是全局，终端里也能用。
  - 没有输出可复制时提示需要开启 Shell 集成。
