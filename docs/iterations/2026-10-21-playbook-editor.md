# PB2：剧本编辑页改版（2026-10-21）

## 问题
名称、说明无标签；「内置 · 示例 · 不自动执行」重复；变量区提示零散；步骤类型为原生下拉；两个复选框与文字错位；超时输入框比命令框宽；步骤之间没有卡片分组，也没有复制和拖动入口；操作按钮离内容较远。

## 设计
- 页头：剧本名 + 「内置」/「草稿」徽标；右侧按钮依次为「导出」「另存为」（内置）「运行」，其中「运行」为主按钮；草稿时主按钮为「保存」，并保留「放弃」。
- 内置只读：页首说明原因（只读示例、不会自动执行），并引导使用「另存为」生成可编辑副本，不再重复示例字样。
- 名称、说明为带标签的表单字段，宽度一致；说明有占位示例。
- 变量为独立小节「变量 N」，无变量时显示虚线框空状态说明。
- 步骤为卡片列表「步骤 N」：
  - 卡片头：拖动手柄（可拖动排序；聚焦后按 ↑ / ↓ 也能调整顺序）、序号、类型（主题 Select）、复制、删除。删除后提示「已删除第 N 步」，与改版前一样不弹确认（编辑器内的步骤编辑，不涉及服务器）。
  - 卡片内：命令用等宽字体编辑框占满宽度；片段类型用主题 Select 选择。
  - 选项行：「执行前确认」「失败即停止」开关，文字紧贴控件；右侧为窄的超时输入，带「秒」后缀。
  - 列表末尾「＋ 添加步骤」。
- 周期提醒小节保持不变。

## 保留
自动保存、草稿保存或放弃、内置另存为、锁定的执行前确认（🔒）、校验占位提示、变量默认值、导出、运行，以及所有 testid。
