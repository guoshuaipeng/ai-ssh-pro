# D46 终端选中「问 AI」带上一条命令与退出码（2026-10-21 第 22 轮）

## 现状
- D6：终端选中文字后右键「问 AI」，选中内容会填进 AI 输入框。
- D22b、D22c：历史里失败的命令可以「问 AI」，带输出。
- 缺口：选中报错文字去问 AI 时，AI 不知道是哪条命令、退出码是多少。

## 方案
- lib/failed-output.ts 在内存里按会话记下最后一条完成的命令和退出码（来自 Shell Integration 回报的退出码，或分块完成事件），不写盘。
- 「问 AI」时如果这条命令在 10 分钟内，且不是敏感命令（isSensitiveCommand），就在选中内容前加一行 `$ 命令   # exit N`，命令本身先经过 redactAuditText 脱敏。
- 内容照常只填进输入框，用户确认后自己发送。
- 局限：没开 Shell Integration、也没开分块时拿不到退出码，这时只带选中内容，和原来一样。
