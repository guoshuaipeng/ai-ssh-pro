# D73 连接中可取消

核对：
- 失败后的处理已有：错误卡片上有「重试」/「重新连接」和「编辑连接」，认证失败还有「检查密钥」（pf5.*），断线后也有重连横幅。这部分不重复做。
- 缺口：连接中的横幅只显示「正在连接…」，没有取消按钮。主机没有响应时，只能关掉标签，或者等到超时，连同标签和位置一起丢掉。
设计：
- 连接中横幅上加「取消连接」按钮。
  - 点击后把这个标签记入 cancelledConnectingTabsRef，并把标签改为「已断开」。
  - 标签本身保留，可以直接用已有的重连横幅或编辑入口。
- 被取消的这次连接，后面如果连上了，会立刻断开；如果失败了，不弹错误卡片，也不记失败。
- 限制：底层 SSH 握手仍会跑到超时才结束，界面不再等它；本轮不改主进程。
