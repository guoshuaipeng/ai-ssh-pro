# D16d 逐条执行进度条

**PM**：D16b/D16c 每一步都弹出提示，五六条命令时提示叠加、遮挡内容。

**方案**
- 命令栏左侧显示进度条：「AI 脚本 2/5 ▬▬ 已填入，按回车执行」，状态：已填入 / 高风险，请确认后执行（红色）/ 执行中… / 已暂停 / 失败（退出码 n），已暂停。
- 按钮：「暂停」（不再自动填入下一条；当前已填入的会清空）↔「继续」；失败时为「发给 AI」「跳过并继续」；始终有「停止」。
- 不再每步弹提示；只在完成和停止时各提示一次。悬停进度条显示当前命令。
