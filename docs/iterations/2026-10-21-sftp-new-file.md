# D71 SFTP 远程新建文件

PM 复查日常路径：在服务器上新建配置、脚本或 README 很常见。现在只能先 touch 再刷新、再双击打开，或者先在本机建好再上传。
核对：SftpPanel 只有「新建目录」，没有新建文件 → 真实缺口。
设计：
- 远程面板「新建目录」旁边加「新建文件」按钮。只读主机、写入被拦截或未连接时禁用；写入前照常走 allowRemoteWrite（包括生产主机提示）。
- shared/sftp-new-file 的 newFileProblem 先检查文件名：不能为空，不能含 / 或 \，不能是 . 或 ..，不能和当前列表里的文件重名。
- 写入前再 stat 一次服务器，列表过期时也绝不覆盖已有文件。
- 用 writeText 写一个空文件，刷新列表后直接在编辑器打开。
