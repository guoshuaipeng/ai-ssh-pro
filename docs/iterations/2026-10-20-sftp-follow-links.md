# D12b SFTP 跟随终端：符号链接与权限不足

**PM**：D12 让远程面板跟随终端 `cd`。两类日常情况体验差：① `/var/www`、`current` 这类符号链接目录在列表里显示成文件，点击会当文件打开；② 终端 `sudo -i` 后 `cd /root`，SFTP 账号无权读取，面板变成错误页，丢掉当前列表。

**现状核查**：`readdir` 返回的是 lstat 属性，符号链接不区分目标类型；跟随失败走通用错误提示。

**方案**
- 列表：对符号链接（最多 256 个）逐个 `stat` 目标，指向目录的按目录显示和打开，指向文件的显示目标大小；名称后加「↪」，悬停提示「符号链接」。目标不存在/无权访问的显示为灰色删除线，点击无动作。
- 跟随：先试探读取目标目录；若为**权限不足**或**不存在**（容器/chroot），面板保持当前目录和列表，顶部显示一条可关闭的说明，例如「终端已进入 /root，但 SFTP 账号无权读取（可能使用了 sudo）。远程面板保持在 /home/demo」。跟随开关保持开启，下一次 `cd` 成功即自动消失。其他错误（断线等）仍走原有提示。
- 不做：不自动用 sudo 读取（安全边界不变）。
