# D89 AI「更多」菜单统一为菜单样式

- 问题（c35 截图发现）：AI 面板「更多」弹层里的每一项都显示为带边框的按钮，和右键菜单（ctx-menu）不一致；也不能用键盘操作。
- 去重：grep docs/iterations 无此项；ContextMenu 组件是另一套定位逻辑，直接替换改动较大，所以只统一样式和键盘交互。
- 方案：
  - 弹层改为 role=menu，加上 class ai-more-menu，样式复用 ctx-menu 的 token：32px 行高、无边框、悬停背景、圆角 popover、阴影。
  - 「清空对话」前加分隔线，并用危险色显示；清空仍然会弹出确认框（原有 confirmDialog）。
  - 打开时焦点放在第一个可用项；↑ / ↓ 在项之间循环，Esc 关闭并把焦点还给「…」按钮。
- 快捷键提示：这几个动作目前都没有绑定快捷键，所以不显示（不新增快捷键，避免冲突）。
