# C2 主题化 Select · P1

## 需求
- 问题：原生 `<select>` 弹出的是系统菜单，在暗色主题下样式割裂，也不能显示禁用原因或附加提示。
- 验收：
  - 新增 `ui/Select` 组件，采用 combobox + listbox 结构，通过 portal 挂载，下方空间不够时向上弹出。
  - 支持键盘操作：↑↓、Home/End、Enter/Space、Esc、Tab，以及按首字母跳转。
  - 禁用项仍然显示，悬停可以看到原因；整个控件禁用时也能看到原因。
  - 替换 5 个高频的原生下拉：AI Provider、AI Model、端口转发会话、审计类型、界面语言。
  - check-ux 新增规则：原生 `<select>` 的数量只能减少。基线保存在 `scripts/native-select-baseline.json`，目前为 39。

## 交互 / UI
- 选项右侧可以显示弱化的提示文字，例如 Provider 的 host、会话的“只读”标记。
- 样式使用 `--color-bg-surface`、`--shadow-menu`、`--radius-sm`、`--fs-sm`。当前选中项用 `--color-accent-muted` 高亮。
- 没有加载态。选项为空时显示“无可选项 / No options”。
