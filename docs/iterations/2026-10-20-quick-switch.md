# D4 Ctrl+P 快速切换 + Ctrl+Tab 按最近使用顺序切换 · P1（高频）

## 需求
- 问题：管理多台主机时，标签一多就要在侧栏和标签栏里来回找。Ctrl+Tab 以前按标签的位置顺序轮转，没法在最近用的两个标签之间来回跳。
- 验收：
  1. Ctrl+P 打开“快速切换”：
     - 先列出已打开的标签，按最近使用排序，当前标签排最后，并标注“当前”。
     - 再列出已保存的主机，显示 `user@host[:port]`。
     - 支持模糊匹配名称和地址。
     - Enter 选标签就切过去，选主机就新建连接。
  2. 标签徽标显示“已连接 / 已断开”，断开用 `--color-warn`。
  3. Ctrl+Tab 按最近使用顺序切换：按一次回到上一个标签；1.2 秒内连续按会沿同一顺序往下走；Ctrl+Shift+Tab 反向。
  4. 没有标签时仍提示“没有标签”（原有行为不变）。
  5. 在浮层里再按 Ctrl+P，会把 `\x10` 发给 shell（bash 里是“上一条历史”），不会把这个键吞掉。

## 交互 / UI
- 与 D3 共用 QuickPick 组件。没有加载态。
- 空状态文案：“没有匹配的标签或主机 / 试试主机名、IP 或用户名”。

## 已知限制
- 已经打开的主机会同时出现在“标签”和“主机”两组里。选“主机”会新建一个会话，这是有意保留的。

- `mruTouch`、`mruOrder`、`rankSwitchPick`，以及 App 里的 `tabChainRef`。
