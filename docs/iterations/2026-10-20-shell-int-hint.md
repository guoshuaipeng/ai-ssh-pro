# D27 首次连接一次性提示开启 Shell 集成（2026-10-20，第 17 轮）

## 需求
Shell 集成默认关闭，但 D14/D22c/D22d 的退出码、目录、失败捕获都依赖它。在合适时机提示一次。

## 设计（沿用 D18 分块提示的克制做法）
- 时机：第一次有普通（非生产、非只读）SSH 会话处于活动且已连接，延迟 2.5s（避开指纹确认、cd 恢复等提示）。
- 只提示一次（aiss.shellInt.hintShown），提示出现即记为已提示，无论是否点"开启"。
- 不提示：已开启、演示主机、本机终端（Windows cmd/PowerShell 不支持）、生产/只读主机（钩子会向会话写一行，保护主机不主动引导，仍可在菜单开启）。
- 按钮"开启"调用现有 setShellIntOn(true)，当前会话随即注入；文案说明不改服务器文件、可随时关闭。
