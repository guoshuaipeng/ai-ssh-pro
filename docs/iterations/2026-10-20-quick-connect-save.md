# D13b 快速连接后保存为主机 + 搜索框识别地址

**PM**：临时连的机器常要再连；标题栏「搜索功能或主机」是另一个高频入口。

**现状核查**：D13 在 Ctrl+P 里识别地址，但未保存目标一律打开表单（表单只有「保存并连接」），标题栏命令面板不识别地址。主进程未指定私钥且无密码时本就会尝试 ~/.ssh 默认密钥。

**交互**
- 未保存目标、有用户名：直接连接（-i 指定的密钥，否则与 OpenSSH 一样试默认密钥），toast「正在连接 x（未保存）」带「保存为主机」→ 打开预填表单。认证失败时标签显示原有错误，同样可以点「保存为主机」补密码。
- 没有用户名：仍打开预填表单。
- 已保存：直接连（不变）。
- 标题栏命令面板（Ctrl+K /「搜索功能或主机」）输入地址或 ssh 命令时出现「连接 x」，行为同上。
- 主进程：私钥路径 `~/…` 展开为用户目录（粘贴 `ssh -i ~/.ssh/k` 时需要）。

**测试**：解析沿用 test-cycle8；截图 `cmdp-qc.png`。

**限制**：侧栏"搜索会话"仍只过滤已保存主机。
