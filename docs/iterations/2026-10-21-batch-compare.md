# D64 批量命令结果按主机对比

核对：BatchExecuteModal 只是逐台列出各主机输出，没有归并，也没有差异提示 → 真实缺口。
设计：
- shared/batch-compare：按 错误 + 退出码 + stdout/stderr 归并（行尾空白和 \r 不算差异）。
- 最大的一组至少 2 台、且没有并列时算「多数」，其他主机标为「与多数不同」。
- 结果上方加汇总：全部一致 / 有几种不同结果、几台不一致 / 没有多数。
- 「问 AI 差异」：把命令、多数结果（只附一份）和每台不一致主机的输出尾部（每段最多 800 字符）交给 AI。整体经 redactAuditText 脱敏、上限 8000 字符，只预填到输入框，由用户发送。
- 不重新执行任何命令。
