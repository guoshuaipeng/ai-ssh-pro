# D66 AI 解释整段终端输出（只补缺口）

核对：
- 右键「问 AI」（D6）已经带上主机和当前目录；D46 补上了上一条命令和退出码；D59 能带最近几条命令。这些不重复做。
- 缺口 1：选中内容超过 4000 字符时只保留尾部，日志开头的上下文和中间的第一处报错都会丢。
- 缺口 2：选中内容本身没有经过脱敏。文件上下文（D39）和最近命令（D59）都已脱敏，选中文字是唯一没做的入口。
设计：
- shared/ask-context 新增 trimLog：多行内容超长时按约 30% 开头、55% 结尾分配，中间只挑报错样式的行（error / fail / exception / denied / traceback / 错误 / 失败 等），并标注省略了多少行。行数很少的内容仍按原来的方式只截尾部，单行内容不受影响。
- App 统一在 AI_ASK_CONTEXT 入口对所有选中内容调用 redactAuditText 脱敏。
- 仍然只预填到输入框。
- trimLog 生成的省略标注写进的是交给 AI 的上下文，不是界面文字，所以不进 i18n。
