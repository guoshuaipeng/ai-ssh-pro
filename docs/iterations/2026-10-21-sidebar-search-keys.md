# D53 侧栏会话搜索键盘补缺（2026-10-21 第 25 轮）

## 核对
- 按标签和备注过滤已存在：profileMatches 匹配 tags 和 note，#前缀只匹配标签，多个关键字要同时命中。
- Enter 只在输入的是地址时直连（D13c）；输入关键字后 Enter 没反应，Esc 不能清空，也不能用键盘进入结果列表。
- 「记住上次关键字」：决定不做。重启后残留的过滤词会让主机看起来「不见了」，误导多于方便。

## 方案
- Enter：先走原来的地址直连；否则只匹配到一台已保存主机时，打开或聚焦它；匹配到多台时不动作，免得连错主机。
- Esc：有内容时清空。
- ↓：选中第一条结果并把焦点移到列表，再按 Enter 就能连接（沿用原来的侧栏 Enter）。
- 占位文字补充「备注，#标签」。
