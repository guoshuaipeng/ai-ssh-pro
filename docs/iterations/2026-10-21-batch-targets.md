# D65 批量执行进阶

核对：
- 批量执行已有全选、清空、侧栏多选预选、只读主机跳过、危险命令确认，以及 D64 的结果归并。
- 缺口 1：不能按分组 / 标签选择目标。
- 缺口 2：结果里看到有问题的主机后，不能直接去那台主机处理。
设计：
- 主机列表上方加「按分组 / 标签」按钮，来源是会话分组和主机标签，只列出有已连接主机的组。
  - 点一次勾选整组，整组都已勾选时再点则取消。
  - 部分勾选的组用虚线框表示。
- 「与多数不同」或执行失败的主机，结果卡片上有「打开终端并填入」。点击切到该主机的终端，把同一条命令填进命令栏，不执行。
- 只读主机仍然跳过，危险命令仍需确认，这些规则不变。
