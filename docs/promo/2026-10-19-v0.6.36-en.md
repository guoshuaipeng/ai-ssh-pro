# AI-SSH-Pro v0.6.36 — desktop multi-session SSH with confirm-first AI assist

AI-SSH-Pro is an open-source (MIT) desktop SSH client aimed at the same daily workflow as Xshell-class tools: multi-tab sessions, SFTP, ProxyJump, port forwarding, host-key confirmation, snippets, import/export, split view, session recording, host inventory, batch execution, a server toolbox, and a resource monitor. On top of that sits **AI Core-A** — observe, plan, then **confirm before run** — so assistance stays in the loop without silently mutating production. The stack is Electron, TypeScript, and React. Passwords, private keys, and API keys stay on-device; encrypted backup is available. The UI ships in Chinese and English.

**Why v0.6.36 is worth installing**

This release is reliability polish, not a marketing feature drop. A **silent-path toast sweep** means actions that used to fail quietly now show a clear toast: broadcast and split when fewer than two sessions are open, reconnect-all, recent connect, read-only unlock, host context opens, playbooks, recordings, and empty or no-host edges. A **demo host disconnect** now notifies the UI correctly, so the Resource monitor returns to the host picker instead of sitting in a half-broken state. Automated coverage for the relevant paths is **E2E 45/45 green**. Around that, recent soft-start work — clearer empty states, CmdK discoverability, safer AI confirmation, and status-bar cues — is best read as overall product maturity, not a fake bullet list of brand-new capabilities.
