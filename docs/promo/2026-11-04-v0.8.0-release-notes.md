## AI-SSH-Pro v0.8.0

轻量桌面版正式发版：Windows 安装包不到 **10MB**（NSIS 约 3–4MB）。

### 亮点
- 安装包体积大幅缩小，下载与升级更快
- 多会话 SSH + AI「确认再执行」
- SFTP、ProxyJump、运维工具箱等常用能力保留
- 产品对外名称统一为 **AI-SSH-Pro**（安装包/快捷方式不再带框架品牌名）

### Windows 下载
- `AI-SSH-Pro_0.8.0_x64-setup.exe`（推荐）
- `AI-SSH-Pro_0.8.0_x64_en-US.msi`
